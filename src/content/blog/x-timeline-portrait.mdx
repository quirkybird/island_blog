我很少认真看自己的首页。多数时候只是往下滑，看到有趣的停一下，然后继续滑。直到我想验证一个问题：推荐算法到底把我当成一个什么样的人？

于是我让 [ego](https://lite.ego.app/) 浏览器把首页「为你推荐」时间线连续滚动采集了一遍，按推文链接去重，取前 100 条，做了一次很粗糙但足够说明问题的盘点。它用的是已经登录的本地浏览器，所以看到的就是我平时看到的那条时间线。

## 一、先交代方法，否则数字没有意义

这次采集只做了四件事：

1. 打开已登录的 [X](https://x.com) 首页，确认当前是「为你推荐」而不是「正在关注」。
2. 连续向下滚动，每次读取当前 DOM 里的 `article`，按推文 URL 去重。
3. 收集到 100 条后停止，保留可见文本，不展开「显示更多」。
4. 用一组关键词做粗分类，并统计账号出现次数与推广标记。

这不是一份严谨的内容分析。它更像一次快速体检：能看出大致结构，但不能当作长期兴趣的定论。

<Callout tone="warning" title="关键词分类会重叠">
一条推文可以同时命中「AI」和「产品」，所以下文的主题数量相加会超过 100。数字应理解为「有多少条推文提到这类话题」，而不是「这类内容占多少比例」。
</Callout>

## 二、内容构成：八成自然内容，近两成推广

100 条里有 19 条带推广或广告标记，其余 81 条是自然内容。推广比例接近五分之一，这解释了为什么时间线里总有一些看起来和日常兴趣无关的插入项。

比「AI 很多」更值得注意的是这些内容的角度。它们很少停留在模型参数或榜单比较，更多在讨论：

- 某个 Agent 工具能不能真的接入日常工作流；
- 多个 Agent 如何分工，主 Agent 调度、子 Agent 干活；
- AI 编程之后，代码审查和交付质量怎么办；
- 开源项目如何被复刻、移植或二次开发；
- 新产品是否只是套壳，还是改变了使用方式。

换句话说，时间线关心的不是「AI 有多强」，而是「AI 能不能用、怎么用、用完谁来负责」。

这张表说明时间线有明显的「头部账号效应」：少数账号占据了相当一部分曝光。它也让「画像」变得更复杂——你看到的内容，一部分是你选择的，另一部分是平台替你选择的。

## 五、这张像到底像什么

把主题、账号和表达方式放在一起，我会这样描述这条时间线：

<Callout tone="insight" title="一句话画像">
一个把 AI 当作日常工具、习惯从产品和落地角度判断技术价值、同时保留少量生活内容的人。
</Callout>

拆开看是三层：

**第一层是工具层。** [Claude Code](https://code.claude.com/docs/en/overview)、[Codex](https://github.com/openai/codex)、[Cursor](https://cursor.com)、DeepSeek Harness 这类东西反复出现。关注点不是「哪个模型跑分高」，而是「哪个工具能少打断我」。

**第二层是产品层。** 新功能、新产品、新公司出现得很密集。时间线像一个持续更新的产品雷达，判断标准通常是「这个东西解决了什么具体问题」。

**第三层是开发者生态。** 开源、插件、复刻、二次开发的内容不少。你对「别人做了什么、我能不能改」的兴趣，明显高于纯消费型内容。

生活、娱乐和社会新闻不是没有，但它们更像背景噪音，而不是主线。

## 六、这个画像不能说明什么

这是整篇文章最重要的部分。上面的结论有几个明确的边界：

<Callout tone="warning" title="样本限制">
  <ul>
    <li>样本来自「为你推荐」，不是「正在关注」。平台排序对结果的影响可能大于个人选择。</li>
    <li>只覆盖约两天，不能代表长期兴趣，也不能代表兴趣变化趋势。</li>
    <li>关键词分类很粗，一条推文可能被重复计入多个主题。</li>
    <li>推广内容混在样本里，会抬高某些主题的命中数。</li>
    <li>只读取了可见文本，没有展开长文、视频和图片里的信息。</li>
  </ul>
</Callout>

因此，它能说明「这两天的推荐流长什么样」，不能说明「我是一个什么样的人」。更不能拿来推断政治立场、消费能力或性格。推荐流是平台和用户共同作用的结果，把其中任何一部分单独归因给人，都不准确。

## 七、如果认真做，下一步该怎么做

这次更像一次手工抽样。如果要把它变成可复用的观察，我会改进四件事：

1. **同时采集「正在关注」**，和推荐流做对照，区分「我选的」与「平台推的」。
2. **拉长时间窗**，按周或按月采样，观察主题是否稳定。
3. **人工标注一小批样本**，用人工结果校准关键词分类的误差。
4. **记录交互而不是只记录曝光**，比如停留时长、展开、点赞，这些比「出现过」更接近真实兴趣。

## 写在最后

我原本以为自己的时间线会很杂。结果它比想象中集中：AI、工具、产品，几乎构成了全部底色。

但这次盘点最大的收获不是「原来我喜欢 AI」，而是意识到推荐流是一面被调整过的镜子。它既照出你，也照出平台希望你成为的样子。偶尔停下来数一数，至少能知道镜子里的哪些部分是自己走进去的。
